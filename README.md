# Playwright Lab

A project for simulating realistic software testing with [Playwright](https://playwright.dev). The main goal is to practice writing end-to-end tests. The file `server.js` is only a sample web app, generated by AI, that serves as the system under test so the practice feels like real-world testing.

> **Localhost only. For learning purposes. Do not deploy to production.**

## About This Project

- This is a **testing practice project**, not a product. The real work is the Playwright tests you write.
- `server.js` is a web app **generated by AI**. It exists only to be tested. Its code quality and design are not the focus.
- The app contains hidden bugs, like a real system under test. Your job is to find them by testing.
- The code was written by AI **without being run**, so some bugs may be unintentional.

## Features of the Sample App

The sample app is a login page plus an iOS-style calculator with per-user history.

- Register with email, password and password confirmation
- Log in with email and password
- Log in with mock Google / Microsoft (OAuth-style redirect, callback and state)
- Cloudflare Turnstile bot protection (3 switchable modes)
- iOS-style calculator (+, −, ×, ÷), one pair of numbers at a time
- Per-user calculation history; click an item to reload its values
- Delete a single history item or clear all history
- Logout
- Thai user interface

## Tech Stack

- **Backend:** Node.js + Express
- **Database:** SQLite via `better-sqlite3` (a single file, `app.db`)
- **Frontend:** plain HTML, CSS and JavaScript, all inside `server.js`
- **Bot protection:** Cloudflare Turnstile (public test keys)
- **Testing:** Playwright Test (the main focus of this project)

## Prerequisites

- Node.js 18 or newer
- npm
- An **internet connection**: the Turnstile widget loads a script from Cloudflare
- macOS is assumed in the examples below; other systems should work too

On macOS, if `better-sqlite3` fails to install, run `xcode-select --install` and try again.

## Getting Started

```bash
# 1. Clone the repository
git clone <your-repository-url>
cd playwright-lab

# 2. Install dependencies
npm install

# 3. Install the Playwright browser
npx playwright install chromium

# 4. Start the app
node server.js
```

Open <http://localhost:3000> in your browser. Stop the server with `Ctrl+C`.

You should see:

```
เปิดที่ http://localhost:3000 (Turnstile โหมด: pass)
```

(The console message is in Thai: "Opened at http://localhost:3000 (Turnstile mode: pass)".)

If you are starting from scratch without cloning:

```bash
mkdir playwright-lab && cd playwright-lab
npm init -y
npm install express better-sqlite3
npm install -D @playwright/test
npx playwright install chromium
# then place server.js in this folder
```

## Bot Protection Modes

Switch the mode with the `TURNSTILE_MODE` environment variable.

| Mode             | Command                                     | Behavior                    |
| ---------------- | ------------------------------------------- | --------------------------- |
| `pass` (default) | `node server.js`                            | Always passes               |
| `block`          | `TURNSTILE_MODE=block node server.js`       | Always blocks               |
| `interactive`    | `TURNSTILE_MODE=interactive node server.js` | User must tick the checkbox |

These use Cloudflare's public **test** keys, so no Cloudflare account is needed.

> **Tip:** A real bot check is designed to block automation such as Playwright. Use `pass` mode for automated tests and the other modes to observe how the page behaves.

## Intended Behavior

This section describes how the app is **supposed** to work. Use it as your specification when testing.

### Password rules

- At least 8 characters
- At least 1 uppercase letter, 1 lowercase letter and 1 digit
- At least 1 special character
- The confirmation must match the password

### Pages and access

| Page        | Description                                                 |
| ----------- | ----------------------------------------------------------- |
| `/login`    | Login page                                                  |
| `/register` | Registration page                                           |
| `/app`      | Calculator. Requires login; otherwise redirects to `/login` |

### Calculator

- Operators: `+`, `−`, `×`, `÷` only
- One pair of numbers at a time (number, operator, number)
- Inputs are whole numbers from **0 to 99**
- Results can be any size and can be negative
- Division results are **truncated** (not rounded) to 2 decimal places, e.g. `2 ÷ 3 = 0.66`
- Dividing by zero shows the message **"เด็กน้อย"**
- Keyboard support: `0-9`, `+ - * /`, `Enter` or `=`, `Backspace`, `Esc` or `C`

### History

- Each user has their own history
- Each item shows the equation, the result and the date and time
- Only the **10 most recent** items are kept; when an 11th is added, the oldest is deleted automatically
- Clicking an item fills its values back into the calculator (it does not calculate again)
- Users can delete one item or clear everything

## Writing Playwright Tests

Create `playwright.config.js` in the project folder:

```js
const { defineConfig } = require("@playwright/test");

module.exports = defineConfig({
  testDir: "./tests",
  use: { baseURL: "http://localhost:3000" },
  webServer: {
    command: "node server.js",
    url: "http://localhost:3000/login",
    reuseExistingServer: true,
  },
});
```

Create `tests/example.spec.js`:

```js
const { test, expect } = require("@playwright/test");

test.beforeEach(async ({ request }) => {
  await request.post("/api/test/reset");
});

test("log in with mock Google", async ({ page }) => {
  await page.goto("/login");
  await page.getByTestId("oauth-google").click();
  await page.getByTestId("mock-account-alice@gmail.com").click();
  await expect(page).toHaveURL(/\/app$/);
  await expect(page.getByTestId("user-email")).toHaveText("alice@gmail.com");
});

test("calculator adds two numbers", async ({ page }) => {
  await page.goto("/login");
  await page.getByTestId("oauth-google").click();
  await page.getByTestId("mock-account-alice@gmail.com").click();

  await page.getByTestId("key-7").click();
  await page.getByTestId("key-add").click();
  await page.getByTestId("key-8").click();
  await page.getByTestId("key-equals").click();

  await expect(page.getByTestId("calc-result")).toHaveText("15");
});
```

Run the tests:

```bash
npx playwright test                            # run all tests
npx playwright test --headed                   # watch the browser
npx playwright test --ui                       # interactive UI mode
npx playwright codegen http://localhost:3000   # record a test
npx playwright show-report                     # open the HTML report
```

## Bug Hunting Rules

- The sample app contains **intentionally hidden bugs** of different types and difficulty levels.
- Test it as a black box: use the app and Playwright only, **do not read the source code**.
- There are no hints and no progress indicator, just like real-world testing.
- Use the **Intended Behavior** section above as your specification.
- Some bugs may be unintentional, because the AI-generated code was never run before delivery.
- When you want to give up or verify your findings, ask the author for a check or a reveal.

## Troubleshooting

| Problem                                    | Solution                                                                                   |
| ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| `Cannot find module '.../server.js'`       | `server.js` is not in the current folder. Run `pwd` and `ls`, then move the file in.       |
| `Cannot find module 'express'`             | Run `npm install` in the project folder.                                                   |
| `better-sqlite3` fails to install          | On macOS, run `xcode-select --install` and retry.                                          |
| File saved as `server.js.txt` or rich text | Do not use TextEdit's rich text mode. Use `nano`, VS Code or `open -e`.                    |
| Login button stays disabled                | The bot check did not pass. Check your internet connection and the `TURNSTILE_MODE` value. |
| `Port 3000 already in use`                 | Another server is running. Stop it with `Ctrl+C` or find it with `lsof -i :3000`.          |
| Old page still shows after an update       | Hard refresh with `Cmd+Shift+R`.                                                           |
